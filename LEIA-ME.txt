CONSULTAR PIX — PROGRAMA LOCAL

COMO USAR NO WINDOWS
1. Instale o Python 3.9 ou mais recente: https://www.python.org/downloads/
   Na instalacao, marque "Add Python to PATH" e mantenha Tcl/Tk selecionado.
   Se ja tem Python com Tkinter, pule esta etapa.
2. Extraia todos os arquivos deste ZIP para uma pasta.
3. De dois cliques em Iniciar.bat.
4. Cole seu token de PRODUCAO do Asaas.
5. Escolha o tipo, digite uma unica chave Pix e clique em Consultar.
6. Clique em Salvar ao lado do token para reutiliza-lo nas proximas aberturas.

O token so precisa ser colado uma vez enquanto a janela estiver aberta.
Ao clicar em Salvar, o token fica no arquivo cache.ini, na pasta do programa.
Ele sera carregado automaticamente nas proximas aberturas.
Esse arquivo contem o token em texto: mantenha-o privado e nao o compartilhe.
O programa nao salva consultas ou resultados no computador.
Para manter o limite mesmo ao fechar e reabrir, salva apenas os horarios de envio.
Manual e Lista compartilham uma consulta a cada 61 segundos (1 minuto e 1 segundo).
Depois de cada envio o botao mostra a contagem regressiva ate liberar nova consulta. Respostas de erro tambem
contam quando houve envio. Erros de preenchimento antes do envio nao contam.
Os horarios sao gravados mesmo sem salvar o token; isso nao grava o token digitado.
O programa usa apenas os componentes padrao do Python.
Nao precisa de servidor ou navegador.
Precisa de internet para consultar o Asaas.

GERAR UM EXE NO WINDOWS
1. Com Python instalado, abra Gerar_EXE.bat com dois cliques.
2. Aguarde a instalacao automatica do PyInstaller e a geracao.
3. Abra ConsultarPix.exe, criado na mesma pasta.
O gerador precisa de internet na primeira vez para instalar PyInstaller.
O EXE pronto nao exige Python.
O cache.ini continua separado ao lado do EXE, preservando token e contador.
Feche ConsultarPix.exe antes de gerar outra versao.
Os arquivos auxiliares ficam em .gerador-exe/. Nao compartilhe seu cache.ini.
O gerador deve rodar no Windows; nao foi executado no ambiente de desenvolvimento.

COMO CONSEGUIR O TOKEN
Na sua conta Asaas aprovada: menu do usuario > Integracoes > Chaves API.
Use a chave de API de producao. Uma chave Pix NAO e o token da API.
Documentacao: https://central.ajuda.asaas.com/hc/pt-br/articles/33618186066331-Como-gerar-uma-nova-chave-de-API-no-Asaas

LISTAS TXT
Abra a aba Lista e clique em Abrir lista. Selecione um arquivo TXT.
Cada linha com um unico conjunto de 11 digitos sera identificada, inclusive CPF
pontuado e telefone com DDD. Linhas vazias, sem candidato ou ambiguas sao ignoradas.
Selecione uma linha e clique em Consultar para enviar somente aquele numero.
Importar e selecionar nao fazem consultas e nao consomem o intervalo.
O modo Manual continua disponivel; os dois modos compartilham o limite de 61 segundos.
A importacao identifica o formato de 11 digitos, nao confirma CPF ou cadastro Pix.

TIPOS DE CHAVE
CPF / CNPJ: pode colar com ou sem pontuacao.
CNPJ: aceita o formato numerico ou alfanumerico.
Telefone: DDD + celular, 11 digitos. O programa tambem aceita +55.
E-mail: informe o endereco completo.
Aleatoria: copie a chave inteira, incluindo os hifens.
CPF e telefone podem ter 11 digitos. Escolha o tipo correto no campo Tipo.

MAC E LINUX
Mac: instale o Python do site oficial com Tkinter e abra Iniciar.command.
Se nao abrir com dois cliques, execute na pasta extraida:
  sh Iniciar.command
Linux: o mesmo comando funciona. Em Ubuntu/Debian, se faltar Tkinter:
  sudo apt install python3 python3-tk
Se o Mac indicar erro de certificado, execute "Install Certificates.command"
na pasta da sua instalacao oficial do Python em Aplicativos.

O QUE O PROGRAMA FAZ
Envia uma consulta GET diretamente para:
https://api.asaas.com/v3/pix/addressKeys/external
Exibe os dados devolvidos pelo Asaas. Nao executa pagamentos ou transferencias.
O botao fica bloqueado enquanto a consulta esta em andamento.
Nao faz consultas automaticas, em lote ou novas tentativas sozinho.
Um erro de rede, de token ou de permissao nao significa chave inexistente.
Chave nao cadastrada e HTTP 404 sem detalhes deste fluxo aparecem em verde suave:
Sucesso, CPF sem Pix cadastrado. O texto acompanha o tipo selecionado.
Mensagens de limite, tentativas excedidas e acesso negado continuam separadas.
Nao verifica se o recebedor e confiavel; apenas mostra o retorno da API.

VERSAO ANDROID
Baixe ConsultaPix-Android.apk no repositorio do GitHub e instale no celular.
Compativel com Android 9 ou superior. O botao Salvar grava o token na pasta
privada do aplicativo, que o recarrega nas proximas aberturas.

LIMITES E CUSTO
O Asaas documenta limite de 5 consultas por minuto, alem da cota de fichas.
Se o limite for atingido, aguarde e clique novamente quando quiser.
O programa nao tem mensalidade. As condicoes de acesso e possiveis tarifas
da API dependem do Asaas; gratuidade por consulta nao foi confirmada.
https://docs.asaas.com/docs/consultar-chave-pix

VALIDACAO
O cliente foi testado com respostas simuladas de sucesso e erro.
Nao foi realizada consulta real: nao foi fornecido um token de producao.
